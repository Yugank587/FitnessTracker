# 🏃 Fitness Tracker

A responsive fitness tracking website built using **HTML, CSS, and JavaScript** to help users monitor daily fitness activities and track their progress.

## ✨ Features

- **User Authentication UI:** Login and sign-up interfaces.
- **Fitness Dashboard:** View daily steps, water intake, calories burned, and heart rate.
- **Daily Goals:** Set personal fitness goals for steps, water, and calories.
- **Workout Timer:** Track workout sessions.
- **Daily Checklist:** Keep track of fitness activities.
- **Workout History:** Review previous workout sessions.
- **Fitness History:** View recorded daily activity data.
- **Weekly Charts:** Visualize fitness progress over time.
- **Local Data Storage:** Save supported account and fitness data in the browser using localStorage.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Browser localStorage

## 🚀 Getting Started

1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in your browser, or use the **Live Server** extension in Visual Studio Code.

## 💾 Data Storage

The current version stores account and fitness information in browser localStorage. Data is not automatically synchronized between devices or browsers.

**Security note:** The current localStorage-based demo authentication is not suitable for production use. Do not use real passwords or sensitive personal information.
